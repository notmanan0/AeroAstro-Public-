# AeroAstro Notes

Study notes for the **MEng Aeronautics & Astronautics** degree at the University of Southampton, written as an [Obsidian](https://obsidian.md) vault.

Each topic note aims to stand on its own. It gives a physical picture of the topic, **full derivations** (including the steps lecturers skip), step-by-step derivation figures, worked examples checked by computation, and a self-study checklist. Each module has a hub note covering topics, concepts and exam skills, plus a formula sheet.

> [!NOTE]
> These are personal revision notes, not official course material. They may contain mistakes, so check anything important against the lectures. Lecture slides, PDFs and transcripts are **not** included: they belong to their authors and the University of Southampton.

This repo is a read-only mirror of a private vault and is updated weekly during term.

---

## How to use it

**Option 1: read on GitHub.** Click through the hubs below. Most maths renders, but wikilinks and embedded figures don't. Obsidian works better.

**Option 2: Obsidian (recommended).**
1. Clone the repo, or use *Code → Download ZIP*:
   ```bash
   git clone https://github.com/notmanan0/AeroAstro-Public-.git
   ```
2. In Obsidian, choose *Open folder as vault* and pick the cloned folder.
3. Start from a module hub. To get updates, run `git pull` inside the folder.

Don't edit the files in place if you want painless updates. Copy a note elsewhere first, or `git pull` may complain.
