# Wing Loading

$$\boxed{\frac WS}$$

Wing loading is aircraft weight per reference wing area. In level flight,

$$\frac WS=qC_L.$$

At stall,

$$V_s=\sqrt{\frac{2(W/S)}{\rho C_{L,max}}}.$$

So higher wing loading raises the speed required for a given lift coefficient. It also tends to reduce wing area for a fixed weight, trading structural/wetted-area benefits against take-off, landing, turn and ceiling performance.

### Scaling

If wing loading rises by 21% with density and $C_{L,max}$ fixed,

$$V_{s,2}/V_{s,1}=\sqrt{1.21}=1.10.$$

### Design use

Wing loading is the horizontal variable in [[Aircraft Constraint Diagram|constraint analysis]]. It is not the same as mass loading: use weight in newtons.
