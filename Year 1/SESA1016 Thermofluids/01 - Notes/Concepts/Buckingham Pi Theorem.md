# Buckingham Pi Theorem

## Definition

> [!note] Definition
> A dimensionally homogeneous relation among $n$ variables involving $k$ independent base dimensions can be expressed using $n-k$ independent dimensionless groups.

## Explanation

Choose $k$ dimensionally independent repeating variables containing all base dimensions. Combine each remaining variable with powers of that set and solve for zero net dimensions.

The theorem determines group structure, not the functional relationship or numerical constants.
